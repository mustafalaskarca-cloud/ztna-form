Before You Begin
This form helps the Information Security team configure your team's access to corporate resources through GlobalProtect (GP) — Teranet's new secure remote access platform replacing Cisco AnyConnect VPN to implement Zero Trust Network Access (ZTNA). Please read these instructions carefully before proceeding.
⚠️
Important — Include All VPN-Dependent Resources
This form must capture every resource your team currently needs VPN to access — applications, servers, databases, file shares, and anything else. If a resource is missed, your team will not be able to reach it after migrating to GlobalProtect. When in doubt, include it.
📌 What You Need to Provide
  • Your team name and the AD usernames of all members who need remote access (AD username only, e.g. jsmith01 — no @teranet.ca)
  • Web application URLs your team accesses via browser — full URL including port if non-standard (e.g. https://app.teranet.ca:8443)
  • RDP and SSH servers (if applicable) — hostname/FQDN, IP address (IP is optional). Only include Dev/UAT and non-production servers; Production servers are handled via CyberArk.
  • Database servers — hostname, IP address, database type, and port or connection string
  • Any other resources — file shares, SMTP, custom port apps, anything you need VPN to reach. If you access any resource through a custom application, provide the full connection string.
✅ What to Include
  • If you open VPN before accessing it — list it.
  • When in doubt, include it. Better to over-report than miss something your team needs.
  • Public websites accessible without VPN are optional to include.
  • If you have a hostname but no IP address, leave the IP field blank.

⚠️ Important: Use the Save Draft button regularly as you fill in the form. Your draft is saved in your browser — if you reopen this form in the same browser, your data will be restored automatically. When you are ready, click Submit on the final step — your JSON file will download automatically.

📬 After Submission
  • You will receive a Submission Reference Number (e.g. ZTNA-2026-0042) — save this for your records and follow-up
  • The Information Security team will review your submission and configure ZTNA access accordingly
  • For follow-up questions, post in the #RolloutSupport Slack channel with your reference number.
